# Buscador de vuelos baratos con grafos (C#)

Guía de Prácticas #04 - Estructura de Datos - UEA

Grafo dirigido y ponderado (lista de adyacencia). Busca la ruta más barata con Dijkstra y la de menos escalas con BFS.
Los datos se leen de `aeropuertos.txt` y `vuelos.txt`.

## Ejecutar
```
dotnet run
```
